# Legacy MongoDB Backend Files

> **⚠️ DEPRECATED**: These files are the original MongoDB-based backend generated by Emergent.
> They have been fully replaced by the new PostgreSQL/SQLAlchemy backend in `backend/app/`.
>
> **DO NOT USE** these files. They are kept temporarily for reference only.

## File Mapping (Old → New)

| Old File | New File(s) | Notes |
|----------|------------|-------|
| `server.py` | `app/main.py` | FastAPI app, lifespan, CORS, routers |
| `core.py` | `app/config.py`, `app/database.py`, `app/constants.py`, `app/exceptions.py`, `app/services/auth_service.py` | Split into focused modules |
| `auth_routes.py` | `app/routes/auth.py` | Auth routes with SQLAlchemy |
| `candidates.py` | `app/routes/candidates.py`, `app/services/authorization.py` | Candidate CRUD + auth helpers |
| `admin_routes.py` | `app/routes/admin.py` | Admin routes with SQLAlchemy |
| `pipeline.py` | `app/routes/pipeline.py` | Pipeline routes with SQLAlchemy |
| `storage.py` | `app/services/storage.py` | S3/MinIO instead of Emergent proxy |
| `worker.py` | `app/services/worker.py` | Background jobs with SQLAlchemy |
| `seed.py` | `app/seed.py` | Database seeder with SQLAlchemy ORM |

The legacy files are archived in `backend/_legacy/` and excluded from the backend image.
